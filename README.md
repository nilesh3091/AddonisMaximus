# Better Anki Stats with goals 📈🎯

An Anki add-on: a study-stats dashboard with goal tracking, rendered as an embedded web view inside Anki.

**Install:** [AnkiWeb #306644033](https://ankiweb.net/shared/info/306644033) — in Anki: Tools → Add-ons → Get Add-ons → code `306644033`

## Layout

- `recall/` — the add-on itself (what Anki loads)
- `dev/` — web UI sources and design assets
